# 🌀 Capsule Chaos

> *Embrace the chaos. Store the memories. Repeat.*

**Capsule Chaos** is a chaotic, AI-powered web experience where randomness meets memory. Built with Google AI Studio, it lets you dive into unpredictable chaos levels, interact with dynamic chaos modules, and secure your moments in a personal **Memory Vault** — all wrapped in a wild, animated interface.

🔗 **Live App:** [capsule-chaos-full-web-play.vercel.app](https://capsule-chaos-full-web-play.vercel.app)

---

## ✨ Features

- 🎲 **Chaos Engine** — A dynamic randomness engine that shuffles and escalates chaos on every session
- 📊 **Chaos Level Tracker** — Visual indicator of how deep into chaos you currently are
- 🧩 **Chaos Modules** — Interactive modules that change behavior based on your chaos level
- 🗄️ **Memory Vault** — Securely store and revisit your chaotic moments
- ⚡ **Powered by Gemini AI** — Google AI Studio integration for intelligent, generative chaos

---

## 🚀 Run Locally

**Prerequisites:** Node.js

1. Clone the repository:
   ```bash
   git clone https://github.com/Aqua-code750/Capsule-chaos-full-web.git
   cd Capsule-chaos-full-web
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set your Gemini API key in `.env.local`:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
